Equations used

k = Gd⁴ / (8D³n)
δ = F / k
τmax = Kw × (8FD / πd³)
Kw = (4C − 1)/(4C − 4) + 0.615/C,   C = D/d

Assumption: close-coiled, round-wire helical compression spring; linear elastic behavior; Wahl factor accounts for curvature and direct shear. This is a preliminary calculation, not a complete spring standard or fatigue-life verification.
